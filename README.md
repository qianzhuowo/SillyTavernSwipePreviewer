# SillyTavern分支预览器 (SillyTavern Swipe Previewer)

一个为 SillyTavern 开发的扩展插件，允许用户预览历史楼层中 AI 生成的所有回复分支（Swipes），而无需改变当前选中的内容。

本插件也支持楼层内跳转、创建分支存档、替换历史楼层内的分支内容等功能。
支持编辑、排序、批量删除、创建独立存档以及时间线式分支图导航。

## 功能特性

- **多楼层支持**：在聊天界面的每一条消息上添加预览按钮。
- **全部分支预览**：一键查看该轮次 AI 生成过的所有候选回复。
- **设置入口**：预览窗口右上角新增“设置”按钮，可配置：
  - 是否将预览按钮移动到酒馆的楼层工具缩略栏（`...` 菜单）
  - 预览时是否应用酒馆正则
  - 是否在未开启渲染时也支持Markdown显示
- **导航系统**：
  - **快速跳转列表**：顶部的数字列表可直接定位到特定分支。
  - **上下翻页**：使用箭头按钮顺序切换查看。
  - **列表折叠**：点击 `123` 图标可展开或收起跳转列表，节省空间。
- **渲染预览**：
  - 预览窗口右上角“渲染预览”按钮：整体启用/关闭 iframe 渲染预览
  - 每个分支标题处也有单独的渲染按钮，可覆盖全局设置
- **分支操作**：
  - **切换楼层内容**：将该分支设为当前聊天选中分支，最新楼层或历史楼层都支持，如果是历史楼层，则是替换成选中的分支，在最新楼层则是跳转。
  - **创建新存档**：在选中的分支处创建新的酒馆分支存档
  - **删除分支**：可在预览列表中删除某一分支（保留至少 1 个分支）
  - **调整顺序**：支持对分支执行上移/下移，快速重排分支顺序
  - **编辑分支**：支持直接编辑任意分支的文本内容并保存

- **纯预览模式**：默认仅预览，不会改变当前聊天的实际选中分支（除非使用「跳转/创建新存档」按钮）。

- **多选删除**：头部垃圾桶进入选择模式，在顶部编号列表选择；支持全选、反选、选择非当前分支、取消选择，至少保留一个 swipe。
- **聊天分支图**：提供树状图预览，直观了解当前聊天的楼层路径与 swipe 旁支，支持搜索、缩放、节点详情、历史消息定位和预览。

默认仅预览，只有显式选择切换、创建存档、编辑、排序或删除等操作才修改聊天。

**键盘操作**：消息入口和顶部按钮支持 Enter/Space；Tab/Shift+Tab 限制在最上层插件窗口，Escape 分层退出选择或关闭窗口。编辑框内 Enter 换行、Ctrl/⌘+Enter 保存，关闭后返回对应控件；原生对话框打开时插件让出键盘焦点。

## 安装方法

1. 在酒馆扩展管理中安装本插件：

```text
https://github.com/qianzhuowo/SillyTavernSwipePreviewer
```

2. 刷新 SillyTavern 页面。升级旧版后也请完整刷新，以清除旧版按钮注册。

## 使用说明

1. 在任意一条 AI 发送的消息上，找到并点击“图层”图标（位于编辑按钮附近）。

2. 在弹出的窗口中：
   - 使用顶部的数字列表快速跳转。
   - 使用左/右箭头按钮翻页。
   - 点击 `123` 图标折叠列表。
   - 绿色边框标记的内容为当前聊天中实际选中的分支。

### 时间线式分支图

- 入口：预览窗口右上角的分支图图标，或聊天输入框旁的原生选项菜单中、“管理聊天文件”下方的“聊天分支树”。扩展设置面板不再显示独立树图按钮。
- **主线**串起各楼层当前选中的候选，例如 `#1·分支2 → #2·分支1 → … → #10·分支3`，便于看清当前文件采用的路径。
- **旁支**展示同层其他 swipe，可切换只看当前路径或显示候选。没有 `swipes` 的消息按一个当前内容计数。
- 支持“char”和“隐藏无分支楼层”两个可叠加的展示选项；前者只保留角色楼层，后者只保留多个 swipe 的楼层。连续隐藏楼层用紧凑的 `…` 标记。
- 总览按钮采用更紧凑的宽度；较长文字会省略，悬停可查看完整楼层与候选说明。
- 缩放（30%–200%）、全部/主干、char、隐藏无分支楼层及工具栏展开状态会自动保存到当前浏览器。关闭重开或刷新页面后沿用，无需重复设置；重置缩放会保存为 100%。
- 这些显示偏好不写入聊天、不跨设备同步；搜索词、详情和跳转位置不保存。浏览器禁止存储时仍可正常使用，但下次打开会回到默认设置。
- 本插件当前仅使用正在打开的聊天，不扫描其他文件。详情仅提示有无独立存档引用；有引用时列出 `extra.branches` / `bookmark_link` 中的存档名称，过滤无效名称并去重。只展示引用，不打开或验证文件是否存在。

## 注意事项

- 按钮直接接入酒馆消息模板，支持普通消息栏和 `...` 菜单；新消息、历史加载和切换按钮位置时会同步，避免重复。自定义主题/扩展需保留原生 `.mes_buttons` / `.extraMesButtons` 容器。
- 更改历史楼层不会重新生成后续对话，后续上下文可能与新候选不一致。
- 生成、消息编辑、原生 swipe 切换或已有保存进行时，不允许执行修改。聊天切换、开始生成或外部修改消息时，旧预览会关闭，避免使用失效索引。
- 创建新存档先将候选应用到源楼层，再创建并打开截至该楼层的独立聊天；会显式保存源聊天分支引用。
- 仍使用酒馆原生保存接口。该接口不提供可靠成功返回值，会吞掉部分网络错误；若酒馆提示保存失败，请确认服务端连接及原聊天，不要继续批量操作。保存期间请勿切换聊天。异常恢复不等于数据库事务，不能回滚第三方事件监听器的全部副作用。
- iframe 使用 `sandbox="allow-scripts"`，允许候选脚本在隔离 iframe 运行，不授予同源权限；这不是禁网沙箱，请只对可信内容开启。
- 自定义主题的强制全局样式仍可能需要个别适配。主题变量即时作用于主窗口，已打开 iframe 需重新切换渲染开关刷新配色。
